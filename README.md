# ICA算法更新，问了kimi：
| 场景                  | 推荐算法                           |
| ------------------- | ------------------------------ |
| 一般 EEG 伪迹去除（眼动、肌电等） | **Extended Infomax (default)** |
| 数据质量差、噪声多、有异常值      | **Robust Extended Infomax**    |
| 大规模数据，追求速度          | **Executable runica**          |
| 周期性/振荡性伪迹为主         | **SOBI**                       |
| 信号时间结构重要，非高斯性次要     | **SOBI**                       |
| 特定非高斯神经信号研究         | **Jade**                       |
| 算法自适应需求             | **SOBI (acsobiro)**            |
